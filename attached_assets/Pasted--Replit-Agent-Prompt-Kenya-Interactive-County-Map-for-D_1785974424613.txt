# Replit Agent Prompt: Kenya Interactive County Map for Debe

You are building an interactive Kenya county map component for **Debe**, a multitenant election campaign management platform. The stack is React + TypeScript + Tailwind CSS + Wouter (routing) + TanStack Query (data fetching).

## Goal
Create a production-ready, interactive SVG tile map showing all 47 Kenyan counties. Each county tile should be color-coded by the leading candidate's vote count, with hover tooltips and click-to-navigate functionality.

## File to Create
`client/src/components/KenyaMap.tsx`
