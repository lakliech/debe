Replit Agent Prompt: Parallel Vote Tabulation (PVT) Module for Debe
You are building a Parallel Vote Tabulation (PVT) module for Debe, a multitenant election campaign management platform. PVT allows campaigns to project election results before the official IEBC announcement using statistical sampling.
Background
In Kenya's presidential elections, the margin of victory is often razor-thin (sometimes <0.5%, triggering automatic recount). Campaigns need real-time projections based on a representative sample of polling stations to:
Know if they're winning before the official announcement
Detect if the race is within recount territory
Identify geographic strongholds and weak areas
Make data-driven decisions about legal challenges or concession
Statistical Methodology
Stratified Probability-Proportional-to-Size (PPS) Sampling
Divide all polling stations into strata (counties or constituencies)
Within each stratum, select stations with probability proportional to registered voters
This ensures high-voter stations (urban areas) are appropriately represented
Bootstrap Confidence Intervals
For each stratum, resample reported stations with replacement (2,000 iterations)
Project stratum totals using design weights
Aggregate to national level
Extract 2.5th and 97.5th percentiles for 95% confidence intervals
Margin Analysis
Projected margin = difference between top 2 candidates' vote shares
Recount territory = margin < 0.5% (Kenyan law)
Win probability = fraction of bootstrap iterations where each candidate wins

Key Design Decisions
Quick reports are separate from full Form 34A submissions. Agents submit simplified counts first for PVT, then submit the full form through the existing agent-submit flow. This allows real-time projections while maintaining audit trails.
Design weights account for PPS sampling. Urban stations with more voters have higher selection probability and lower weight. Rural stations have lower probability and higher weight. This ensures unbiased national estimates.
Bootstrap resampling within strata. This preserves the stratified design and properly accounts for the complex sample design when computing confidence intervals.
Auto-compute on each quick report. Every new report triggers a fresh projection, so the dashboard updates in real-time during election night.
Recount threshold is 0.5%. Hardcoded to Kenyan presidential election law, but could be made configurable per-election type.
